# 헌법 탐정단 : 사라진 시민의 권리를 찾아라!

초등 5~6학년 헌법교육 동아리용 **비주얼 노벨 추리 게임**입니다.
`index.html` 파일 하나로 실행되며, 설치가 필요 없습니다.

## GitHub Pages로 링크 만들기

1. GitHub에서 새 저장소(Repository)를 만듭니다. (예: `constitution-detective`, Public)
2. **Add file → Upload files**로 `index.html`(필요하면 이 `README.md`도)을 올리고 **Commit changes**를 누릅니다.
3. 저장소의 **Settings → Pages**로 갑니다.
4. **Source**를 `Deploy from a branch`로, **Branch**를 `main` / `/(root)`로 정하고 **Save**를 누릅니다.
5. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소가 생깁니다. 이 링크를 학생들에게 나눠 주세요.

## 게임 구성 (CASE 01만 약 40분, 전체는 2~3차시)

| 단계 | 제목 | 핵심 개념 |
|---|---|---|
| 프롤로그 | 헌법 탐정단에 오신 것을 환영합니다 | 헌법의 의미와 필요성, 헌법 전문 |
| CASE 01 | 사라진 게시판 (방탈출 확장판, 약 40분) | 표현의 자유와 책임(제21조 ①·④), 사생활(제17조), 학교 규칙과 절차 |
| CASE 02 | 똑같이 나누었는데 왜 불공평하지? | 평등권, 실질적 평등과 차별, 헌법-법률-학교 규칙의 관계 |
| CASE 03 | 우리 반 헌법을 뒤집어라 | 민주주의, 다수결의 원리와 한계, 소수자 보호, 학급 헌법 만들기 |
| CASE 04 | 사라진 판결문 | 국회·정부·법원·헌법재판소의 역할, 권리 구제, 모의 헌법재판·모의국회 |
| CASE 05 | 헌법마을의 마지막 선택 | 가치 충돌(자유·평등·안전·환경·참여), 헌법 실천 선언문 |

## 교사용 모드

- 타이틀 화면 오른쪽 아래 **👩‍🏫 교사용 모드** → 비밀번호 **1948**
- 확인할 수 있는 것: 플레이 시간, 해결한 사건, 힌트 사용, 단서, 선택한 판단, 성찰 내용, 사건별 토론 질문
- **결과 복사 / 텍스트 파일로 저장**으로 학생 기록을 모을 수 있습니다.
- CASE 01 방탈출 정답 요약(비밀번호·시간 계산 등)도 교사용 모드에서만 볼 수 있습니다.
- **모든 사건 열기**로 원하는 사건부터 미리 해 보거나 수업할 수 있습니다.
- 비밀번호를 바꾸려면 `index.html`에서 `const TEACHER_PIN = '1948';`을 찾아 숫자를 바꾸세요.

## 알아 두기

- 진행 상황은 **그 기기의 브라우저에 자동 저장**됩니다. 다른 기기나 시크릿 창에서는 이어지지 않습니다.
- PC·태블릿(가로 화면)에 맞춰져 있습니다. 화면 크기에 맞게 자동으로 확대·축소됩니다.
- 인터넷이 연결되어 있으면 게임용 한글 글꼴이 적용됩니다. (연결이 없어도 기본 글꼴로 실행됩니다)
- 게임에 나오는 학교·인물·사건은 모두 가상입니다. 헌법 조문은 대한민국헌법의 실제 조문을 인용했습니다.
